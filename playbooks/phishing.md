# Phishing Response Playbook

1. Preserve the suspicious email.
2. Identify all recipients.
3. Quarantine or remove the message where possible.
4. Check whether links were opened.
5. Check whether credentials were submitted.
6. Review authentication and MFA activity.
7. Reset compromised credentials when necessary.
8. Revoke active sessions where appropriate.
9. Search for similar phishing messages.
10. Check for data exposure or financial fraud.
11. Inform affected users.
12. Document the incident and lessons learned.
