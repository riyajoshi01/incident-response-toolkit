# Incident Response Toolkit

## Week 2 Cybersecurity Internship Project

This project presents a practical Incident Response Plan for handling cybersecurity incidents in an organization.

The main objective is to understand how an organization should prepare for, detect, contain, investigate, eradicate, and recover from cyber attacks.

## Project Objectives

- Create a structured Incident Response Plan.
- Define roles and responsibilities during a cyber incident.
- Classify incidents according to their severity.
- Provide practical response procedures.
- Create incident-specific playbooks.
- Document evidence, communication, recovery, and lessons learned.
- Provide a quick checklist for incident responders.

## Incident Response Lifecycle

1. Detection and Reporting
2. Triage and Validation
3. Incident Declaration
4. Containment
5. Investigation
6. Eradication
7. Recovery
8. Lessons Learned and Closure

## Cybersecurity Framework

The project follows established incident response practices and references NIST SP 800-61 Rev. 3 and the NIST Cybersecurity Framework (CSF) 2.0.

## Purpose

This project demonstrates a practical approach to responding to cybersecurity incidents and shows how organizations can reduce the impact of attacks, restore affected systems, and improve their security after an incident.
