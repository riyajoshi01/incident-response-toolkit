# Incident Severity Matrix

| Severity | Description | Example |
|---|---|---|
| P1 Critical | Major threat to critical operations or sensitive information | Ransomware affecting production |
| P2 High | Significant compromise with serious impact | Privileged account compromise |
| P3 Medium | Contained incident with limited impact | Malware on one endpoint |
| P4 Low | Minor event or false positive | Blocked phishing attempt |

Severity should be determined using both technical indicators and business impact.
