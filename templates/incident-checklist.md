# Incident Response Quick Checklist

- [ ] Detect and report the incident
- [ ] Create an incident ID
- [ ] Validate the event
- [ ] Assign severity
- [ ] Appoint Incident Response Lead
- [ ] Identify affected systems and accounts
- [ ] Preserve evidence
- [ ] Contain the threat
- [ ] Investigate the scope and attack path
- [ ] Eradicate malicious access
- [ ] Recover affected systems
- [ ] Monitor restored systems
- [ ] Complete required communications
- [ ] Document impact
- [ ] Conduct lessons learned
- [ ] Assign corrective actions
- [ ] Close the incident
